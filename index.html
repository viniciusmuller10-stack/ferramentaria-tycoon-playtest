⬇ Baixar instalador

Windows 10/11 • instalação única, sem pedir administrador

Como instalar

  1. 1. Instale uma única vez. Baixe e abra o Setup_FerramentariaTycoon_Playtest.exe. Se o Windows avisar “PC protegido”, clique em Mais informações → Executar assim mesmo (o instalador ainda não é assinado).
  2. 2. Abra pelo atalho da Área de Trabalho. O Launcher confere a versão e baixa sozinho só o que mudou. Depois é só jogar.

Dentro do jogo, aperte F8 para tirar um print automático e abrir este portal. Aqui, cole com Ctrl + V.
